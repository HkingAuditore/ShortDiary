06{{ASSET:crayon/circle-mark}}

动效剧场

原则不变：transform/opacity 优先、150–550ms、reduced-motion 全关。升级点在于曲线与编排——弹簧过冲、二次回弹、错峰落纸。进场自动播放一次，右侧可重播。

① 弹簧落纸

drop-spring · 26px 落下 → 过冲回弹 → 归位带微转角

② 胶带粘贴

tape-stick · scaleX 从 0.25 拉开 + 角度回弹，像按上去的

③ 蜡笔描画

crayon-draw · stroke-dashoffset 900ms 描完，回声笔慢半拍

④ 纸页翻开

unfold-in · rotateX 32° 翻开，阴影随高度同步变深

⑤ 微风摇曳

flutter · 挂在胶带下的卡片 ±1.8° 摆动，3.2s 呼吸感

⑥ 依次落下

drop-queue · 90ms 错峰，队列感来自节奏而非延迟堆积

⑦ 星星收藏

star-pop · scale 0→1.3→1 + 旋转归正，比 hover:scale 有弹性

ink-dot-2 · 上浮 + 轻微放大，替代纯 opacity 闪动

07{{ASSET:crayon/circle-mark}}

集成指南

素材与 token 全部对齐现有 globals.css，四步并入。

① 放置素材

把 art-kit/assets/ 整体复制到 public/art/，按 <img src="/art/papercut/hills.svg"> 或 CSS background 引用。全部是无依赖的纯 SVG，支持 <img>、background、内联三种用法。

② 撕边升级

clip-path 多边形换成 SVG 位移 mask（本页 .entry-after 即效果）：paper-motion.css 里的 .torn-fiber-1..4 四个变体，保留「同卡片固定变体」的种子约定。

③ 动效替换

paper-motion.css 与 globals.css 同名 token 直接合并：--ease-spring、drop-spring、tape-stick、crayon-draw、unfold-in、flutter、star-pop。原 paper-drop 可保留为兜底。

④ 手写字体

现有 --font-hand（Segoe Script）无中文字形，中文全部回退到系统字体。建议换成： 
--font-hand: "Zhi Mang Xing", "Gloria Hallelujah", cursive;
--font-serif-cn: "LXGW WenKai Screen", "Songti SC", serif;

分层原则

剪纸只出现在结构位（空状态、区块底、照片内容）；蜡笔只出现在情绪位（高亮、圈注、心情）；手绘只出现在批注位（2–12 字）。正文永远在高对比米白卡上，simpleMode 关闭全部纹理与撕边。

再生成

所有素材由脚本生成（seeded，可复现）： 
node art-kit/tools/generate-assets.mjs
改参数（抖动幅度、色板、种子）重跑即可全家更新，模板 art-kit/tools/template.html 会同步重新组装本页。
