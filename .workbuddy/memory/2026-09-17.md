### 冒烟暴露并修复的真实缺陷（都不是测试写法问题）
1. **UUIDv7 生成超长**：最后一段用了 8 字节(16 hex)，正确是 6 字节(12 hex)，导致所有 `insert into users` 报
   `invalid input syntax for type uuid`。→ `lib/utils/uuid.ts`
2. **口令哈希与验签格式不一致**：`hashPassword` 少了 PHC 前导 `$`，而 `verifyPassword` 按 5 段解析，
   结果任何人（含刚创建的账号）都登不上。→ `lib/crypto/envelope.ts`
3. **`DATABASE_URL=` 空串导致整份 env 校验失败**：`z.string().url().optional()` 不接受空串，
   凡调用 `getEnv()` 的接口（含 `/api/ready`）一律 500。→ `lib/env.ts` 加 preprocess 归一化。
4. **任务拾取 SQL 语法错**：`type IN ${sql.join(...)}` 少了括号，队列轮询每 5 秒刷一条错误。→ `lib/jobs/queue.ts`
5. **迁移漏列**：`exports` 表缺 `updated_at`（schema 用了 timestamps，0003 迁移没建），导出全 500。
   → 新增 `drizzle/0004_exports_updated_at.sql`（迁移只追加，不改写已应用的）。
6. **流式下载被当成 JSON 信封**：`defineRoute` 只认 `NextResponse`，而导出/图片路由返回原生 `Response`，
   结果下载到 61 字节空壳。→ 判定改为 `instanceof Response`，返回类型放宽为 `Response`。
7. **PGlite 数据目录父级不存在会 ENOENT**；多语句迁移在 PGlite 走扩展协议会失败→加 `execScript()` 走 `exec()`。

### 环境要点（本机）
- curl 必须 `--noproxy '*'`，否则 `http_proxy=127.0.0.1:7876` 会把 localhost 请求代理成 502。
- Bash 工具里 `cmd &` 起的进程会随调用结束被回收；要常驻服务必须用 `run_in_background`。
- **PGlite 单进程独占 `.data/pgdata`**：跑 migrate/bootstrap/seed 前必须先停 dev/start，否则脚本卡死。
- 改了服务端代码后必须重新 `npm run build`，`npm start` 跑的是 `.next` 旧产物。

### 白屏修复（16:55–18:30）
用户打开应用整页空白。定位链路：curl 确认 SSR HTML 完整、10 个 chunk 全 200 →
Edge + playwright-core 诊断：5 条 CSP 违规（inline script 被拦）、水合没跑、React 清空 SSR 树。
**根因**：CSP 放在 `next.config.ts` 静态 headers，Next 无法给内联引导脚本注入 nonce。
**修复**：CSP 移到 `middleware.ts`（设请求头 + 响应头，Next 自动从请求头 CSP 提取 nonce），
`next.config.ts` 删掉 CSP。验证：登录页/6 个页面全部渲染，无 CSP 违规，smoke 24/24。

连带修的两个坑：
1. 加 middleware 后构建炸 `Can't resolve 'stream'`（cos-nodejs-sdk-v5 经 instrumentation 进 edge bundle）——
   instrumentation 的 Node import 必须写在 `if (process.env.NEXT_RUNTIME === "nodejs")` 分支内部，
   webpack 解析期才会跳过死分支；先 return 再 import 无效。
2. 沙箱里 `bash scripts/smoke.sh` 全 000：沙箱只放行 bash **直接子进程**的网络请求，脚本里的 curl 是孙进程。
   用 `source scripts/smoke.sh` 即可。cookie jar 也别用 mktemp（/tmp 是 MSYS 路径，Windows curl 认不了），
   改放 `.data/smoke-cookies-$$.txt`。

其他：新增 `app/icon.svg` 消掉 favicon 404；middleware 用 btoa 代替 Buffer；unsafe-eval 仅 dev。
